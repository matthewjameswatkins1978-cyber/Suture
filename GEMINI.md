# Threadmoth extension

Threadmoth is an optional local executable used for precise, source-preserving
mutation of existing files. The canonical command is `threadmoth`; it must be
installed on the user's PATH separately from this extension.

When a requested change is a bounded mutation of an existing supported file,
activate the bundled `threadmoth` skill. Discover the installed version and
capabilities before choosing a provider. Preview uncertain edits, treat
`REFUSED` as a deliberate safety result, and preserve the returned certificate.
Do not use Threadmoth for Git, builds, tests, formatting, network work, or new
files. Never bypass a refusal with a broader raw edit without user
authorization.
